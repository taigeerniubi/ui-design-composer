# 组合案例与冲突处理

从与当前任务相近的案例中取用思路，并根据内容量、频率、设备和已有产品约定调整。

## 同时明确布局、配色、字体

下面是可采用的起点。已有品牌或组件规范时先结合规范选择；场景不构成固定绑定。

| 场景 | 布局与信息 | 配色候选 | 字体候选 | 关键状态 |
| --- | --- | --- | --- | --- |
| 视频编辑器 | 多栏工作台，属性分组与渐进式披露 | 石墨灰 · 青柠；画布另设中性灰 | IBM Plex Sans SC＋Plex Sans，时长使用等宽数字 | 选择对象、参数修改、导出中、结果与失败重试 |
| 通用 AI 工具 | 按对象或会话组织主从区域，按需展示进阶参数 | 雾白 · 深青 | 思源黑体 SC＋Inter | 提交、排队、生成、停止请求、部分输出、已完成或未保存 |
| 品牌官网 | 单列或分屏，清晰标题与下一步 | 珍珠灰 · 海军蓝 | 思源黑体 SC＋Manrope；文化内容可尝试宋体标题 | 行动入口、表单校验、提交结果与恢复 |
| 参数对比 | 同行同指标，保持横向对齐 | 冰白 · 钴蓝 | 思源黑体 SC＋Inter，数值按列对齐 | 选中、筛选、展开指标、加载错误与无结果 |
| 设置页 | 按用户概念分组，常用项常驻 | 冷灰 · 鸢尾紫或沿用品牌色 | 思源黑体 SC 或平台字体，明确控件与说明层级 | 原值、已修改、保存中、成功、失败与未保存离开 |

配色和字体分别见 [配色指导](color-system.md)、[字体指导](typography.md)。状态的通用规则见 [组件状态](component-states.md)。

## 视频编辑器：让用户持续操作同一对象

主要任务：选择素材、修改片段、预览效果并导出。

| 区域 | 可组合的方法 | 预期作用与关键状态 |
| --- | --- | --- |
| 整体 | 多栏工作台＋可收起面板 | 同时访问素材、预览、时间轴与属性；预览保持足够空间，收起面板后能恢复。 |
| 素材区 | 规则网格＋缩略图识别＋搜索筛选 | 快速找到素材；保留筛选条件，区分空素材库与没有筛选结果。 |
| 属性区 | 明确分组以支持层状蛋糕扫描＋渐进式披露 | 按画面、音频、字幕等用户概念组织；常用参数直接展示，高级参数展开，折叠时提示重要的已修改状态。 |
| 画布和时间轴 | 直接操控＋情境化操作＋数值输入 | 对当前对象拖动、裁剪和编辑；明确选中对象，支持精确调整和键盘操作。 |
| 编辑与导出 | 即时预览＋撤销＋真实状态反馈 | 让用户理解修改与结果的对应关系；区分处理、完成、失败，失败后保留导出设置。 |

窄屏时可以切换素材、预览和属性面板，保留播放位置与选中片段。不要仅把所有栏等比压窄。

### 导出操作从点击到结束

| 触发与阶段 | 反馈及允许操作 | 结果与恢复 |
| --- | --- | --- |
| 点击导出 | 按下反馈；校验格式、目标与必要参数，失败时定位相关设置 | 校验通过才创建任务，输入继续保留 |
| 提交与排队 | 显示提交中或等待处理，限制同一次重复导出；能否取消以真实能力为准 | 得到任务标识后跟踪同一任务，不能直接显示完成 |
| 渲染与写入 | 显示可靠阶段或真实进度；保持按钮尺寸和文案可读，提供实际可用的取消或后台入口 | 等待实际结果，进度满格时如仍在写入就继续说明 |
| 成功 | 更新输出记录，显示完成对象和查看、下载或继续编辑入口 | 清除忙碌限制；下一次导出按当前参数重新操作 |
| 失败 | 保留参数，显示原因、重试及返回修改入口；错误文字不能被固定高度裁切 | 按失败范围重试，保留已生成的有效结果 |
| 取消或连接中断 | 取消请求后等待确认；连接中断时先核实任务结果 | 说明输出是否保留；结果未知时查询原任务，避免重复创建 |

## 产品介绍页：理解价值后决定下一步

主要任务：理解用途、判断是否适合，并开始体验或进一步了解。

- 骨架可用单列分区或适合内容的分屏；内容较少的首屏可以参考 Z 型构图。
- 优先表达用途与价值，接着给出可信的产品内容、适用条件和下一步入口；按实际决策需求排序。
- 下方长内容使用有信息量的小标题，支持层状蛋糕扫描。
- 低频技术细节可按需展开，影响购买或使用决定的条件应容易找到。

若主标题、产品图和按钮都具有强烈视觉重量，先调整重点之间的关系。无需强行让用户视线画出 Z 字，也无需每个分区都交替左右排布。

## 套餐或参数对比：降低来回记忆的负担

主要任务：比较同一组指标，选择符合需求的方案。

- 使用对齐的比较表；同一行表示同一指标，单位与字段含义一致，支持逐行往返扫描。
- 根据用户决策顺序分组指标，突出真实差异；推荐方案应说明依据。
- 更多指标可以整组展开，保持各方案之间的行对应关系。
- 窄屏根据任务选择可理解的横向滚动、固定标签或“选择对象后比较”，并保留表头关系。

给每个方案使用独立且高度不一的折叠区，会破坏横向对齐。将共同指标一起展开更容易保持比较上下文。

## 设置页与表单：找到设置并理解修改影响

主要任务：定位一个设置，修改并确认结果。

- 按用户概念分组，使用能概括内容的小标题；设置很多时考虑搜索、目录或分类导航。
- 常用字段直接显示，低频进阶项按需展开；选中某选项后再出现相关字段。
- 默认值减少重复输入；标签、帮助和校验说明取值含义及影响范围。
- 保存或提交后给出明确状态；返回、切组与校验失败时保留输入。

如果任务有真实阶段依赖，可以改用分步完成。仅有少量并列字段时，通常不必增加步骤。提交后应定位第一个错误，并使包含错误的折叠区域可见。

## 素材或作品库：先判断用户在浏览还是比较

- 重视图片发现、图片高度不同：可以采用瀑布流，并处理加载跳动与阅读顺序。
- 重视文件名、时长、尺寸等并列比较：采用规则网格、列表或表格更方便对齐。
- 需要连续处理列表中的对象：考虑主从布局，保留选中项、筛选与返回位置。
- 操作可以在选中后出现，也可在悬停时增强可见性；键盘与触屏仍有可达入口。

## 组合冲突的处理

| 冲突 | 判断与处理 |
| --- | --- |
| 渐进式披露增加了高频操作成本 | 将高频项移至常驻区域，或提供易发现的快捷入口；保留低频项的展开层级。 |
| 情境化操作缺乏可发现性 | 给对象明确的选中线索，在合适位置保留工具入口、标签或首次使用提示。 |
| 卡片和分组过多，阅读被打断 | 合并同一任务中的内容，优先用间距表达关系，边框只在有助于归属时使用。 |
| 视觉动线与用户任务不一致 | 先确保任务中的信息顺序与操作关系清楚，再调整位置、对比和留白。 |
| 分步完成方便引导，但妨碍熟练用户 | 保留返回修改与状态，对可独立访问的步骤提供适当跳转；避免凭空增加必经步骤。 |
| 窄屏隐藏面板后失去上下文 | 显示当前对象与必要摘要，重新打开时恢复相关选中状态、输入与位置。 |

## 调用示例

```text
使用 $ui-design-composer 为一个有素材、预览、时间轴和属性区的视频编辑器设计 UI。明确布局、配色和中英文字体，说明窄屏调整，并覆盖导出从点击、进行中到成功、失败和取消的状态。
```

```text
使用 $ui-design-composer 评审这个设置页的布局、配色、字体和保存状态。检查分组、渐进式披露、未保存修改、处理中、成功与失败恢复，给出具体调整建议，先提供方案。
```

```text
使用 $ui-design-composer 比较规则网格、瀑布流和主从布局，判断哪种更适合这个素材库的任务，并说明取舍。
```
